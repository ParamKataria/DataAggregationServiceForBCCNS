# Reference board — metadata desk

Status: viewed sources.

## Direct
- Omeka item add and item browse (https://info.omeka.net/build-a-website/add-items/). Dublin Core is the first tab. The browse list leads with Title, Creator, Item Type, and Date, and keeps the rest behind details.
- ArchivesSpace staff record creation (https://archivesspace.org/archives/231272). A staff desk for making records, separate from the public catalog.

## Adjacent
- Harvard CHoM Omeka field rules (https://harvardwiki.atlassian.net/wiki/spaces/hmschommanual/pages/49447643). Title, date, type, and subject stay in their own fields. The description does not repeat them.

## Anti-references
- A marketing hero with three feature cards.
- A purple dashboard that treats a cataloging desk like a SaaS landing page.
